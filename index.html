Инструкция по настройке бота Telegram
  1. Открой Telegram и найди бота @BotFather
  2. Отправь ему команду /newbot и следуй подсказкам для создания
  3. Скопируй полученный **HTTP API Token** и вставь его в поле ниже
  4. Чтобы узнать твой **Chat ID**, напиши боту @userinfobot в Telegram
  5. Вставь твой цифровой ID в поле "Твой Telegram Chat ID" и нажми "Тест"!
